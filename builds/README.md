# Browser builds

This release includes a matching v1.6.4 `CritterCare-itchio.zip` and generated files in `web/`.

After editing, open the project in Godot 4.7.2 and choose **Project → Tools → Export CritterCare for itch.io**. This updates both `builds/web/` and `builds/CritterCare-itchio.zip` from the current source. Upload the new ZIP to your existing itch.io HTML Game page.

Use these canonical build locations; the old duplicate `critter_care_web_version/` directory is excluded from the release.
