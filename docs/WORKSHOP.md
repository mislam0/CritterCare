# A short CritterCare workshop

New saves open a guided green-arrow tour. Returning players can replay it from Settings; Reset progress also starts it again. An instructor can use these four phases without changing the game.

Before a classroom demo, open the `···` settings menu and choose the **Game level** that fits the group. Kindergarten - Elementary level uses slow IF/THEN explanations and avoids assuming programming vocabulary. Middle - Highschool can progress through three stages; College through four. Every group starts with the same beginner games. New stages teach ideas before asking players to apply them.

1. **Quick introduction — 1 minute.** Explain that Pip is a virtual pet who can help us notice how programs make decisions. Follow the short tour first, or skip it for an instructor-led demo and read his first idle lesson. Ask: “How does the game know whether Pip is being held?”
2. **Free play — 4 minutes.** Click his head, pick him up, move him in different directions, put him down, and offer a treat. Read each bubble with Next and Back, then choose Done. Bubbles stay visible until the learner is ready. Visit Knowledge to read one code example. Pet and feed him twice to discover variables and functions.
3. **One adventure — 3–5 minutes.** Start Berry Detective for conditions, Loop Garden for repetition/debugging, or the Pop Quiz to revisit encountered concepts. There is no time pressure. Bring earned treats back to Pip and visit the Shop with the earned coins. Ask what happens to the coin number when an item is bought.
4. **Wrap-up — 2 minutes.** Open the games menu to see earned stage badges. Ask each learner to name a real interaction, its condition or event, and its effect. Finish by finding that concept in Knowledge.

## Find every discovery

| Discovery | Action that introduces it |
| --- | --- |
| If / else | Watch Pip rest after the greeting |
| Events | Short-click the head |
| Variables | Pet again |
| Booleans | Hold Pip to pick him up |
| Position / Vector2 | Move him at least a short distance while holding |
| Gravity / cause and effect | Release him above the floor |
| Feeding conditions | Offer the first treat |
| Functions | Offer a second treat |
| Loops | Let a snack's three chew cycles finish |
| Timers | Leave him resting until he washes his face |
| AND | Reach the second half of Berry Detective and read its feedback |
| Repeat counts / debugging | Run a loop in Loop Garden and read its result |

Pip queues new home lessons so they do not interrupt one another. A lesson joins Knowledge when it appears. Choose Done on the current bubble to move to the next queued discovery. Click Knowledge to read the full saved words under Pip says, followed by the explanation and code. Closing menus resumes home animation and the lesson queue.

Suggested reflection: “If you wanted Pip to wear a party hat only when he is happy AND you have won a game, what two checks would you combine?”

Use **Reset progress** from the settings menu when you want the next group to start from zero. After confirmation, it clears unlocked lessons, stage badges, coins, all Shop purchases and equipment, scores, and care counts; starter treats return while keeping the selected level and comfort settings.

## Continue across sessions

Win each of the three activities to earn the current stage's badges. The quiz must contain at least three encountered lessons to count for a badge. In First steps, play both mini-games or explore Pip's interactions to meet enough concepts. Later stages have short lesson pages before their games; read them, then try the challenge. Quizzes only use concepts the learner has actually seen.

Middle–Highschool adds OR/NOT, comparisons, variable updates, ELIF, parameters, and running totals. College continues into grouped checks, lists, nested loops, and boundary testing. The stage dropdown keeps earlier practice available. Switching levels preserves badges and purchases; the lowest level always stays at the original difficulty.

For a concrete variables example, finish an activity, note the coin balance, buy a 20-coin leaf hat, and subtract its price together. Equip it, unequip it, and equip it again: no more coins are spent because ownership is saved separately from the equipped appearance.
