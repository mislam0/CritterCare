# Decor Set templates

All ten themes already include finished room accents. These transparent
templates are for creating replacements or adding custom pieces.

Keep each canvas at its original size, use flat colors and transparent
backgrounds, and remove all guide marks before exporting. Copy finished PNGs
to `assets/shop/room/decor_sets/<theme>/<piece>.png`.

See [DECOR_SETS.md](../DECOR_SETS.md) for dimensions, anchors, and fallback
behavior, and [SHOP_ART.md](../SHOP_ART.md) for the current art direction.
