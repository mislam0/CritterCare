# Ten shop themes

The shop contains Nature, Study, Smart Casual, Halloween, Christmas, Pixel
Knight, Easter, Brainrot, Thanksgiving, and Bear Spirit. Each theme has three
pet items and three room items, for 60 purchases total. Decor Sets also equip
six matching room accents without extra purchases.

Use flat, front-facing shapes, simple colors, and no swords. Pixel Knight stays
pixelated; bear motifs belong only to Bear Spirit. Preserve purchase IDs,
prices, theme membership, and shared placement geometry.

See [SHOP_ART.md](SHOP_ART.md) for artwork sources and validation, and
[SHOP_FIT_GUIDES.md](SHOP_FIT_GUIDES.md) for the pet and room canvases.
